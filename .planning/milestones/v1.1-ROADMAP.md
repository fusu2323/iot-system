## Milestone Summary

**Key Decisions:**
- Device sync in trigger(), not toggle() — centralized device state management
- Enable → all linked devices status=1; Disable → all linked devices status=0
- Scene mutex_group: VARCHAR(50), human-readable string names
- toggle() uses @Transactional for atomic enable+auto-disable
- getRecommendations() returns GroupedRecommendationResponse with optional type filtering

**Issues Resolved:**
- AUTH-01/02: Clear error messages for duplicate username/email at registration
- SCENE-01/04: Scene mutex groups with automatic disable
- SCENE-03: Scene-device state sync on trigger
- CONTENT-01/02/03: Expanded content data (24 entries)
- CONTENT-04: Content list type filtering (already implemented, verified)
- RECOMMEND-01/02/03: Type filtering, grouped response, configurable weights

**Issues Deferred:**
- None

**Technical Debt Incurred:**
- Pre-existing build errors in UserServiceImpl.java (BusinessException constructor mismatch) — not from v1.1 changes
