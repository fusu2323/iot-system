# REQUIREMENTS.md — Milestone v1.1 (Archived)

## v1.1 Bug修复与权限增强 — COMPLETED

### 用户认证 (AUTH)

- [x] **AUTH-01**: 用户注册时，如果用户名已存在，返回明确错误信息"用户名已存在，请尝试其他用户名"
- [x] **AUTH-02**: 用户注册时，如果邮箱已被注册，返回明确错误信息"该邮箱已被注册"
- [x] **AUTH-03**: 管理员可查看所有用户列表
- [x] **AUTH-04**: 管理员可删除普通用户
- [x] **AUTH-05**: 普通用户不能删除其他用户（只能删除自己）
- [x] **AUTH-06**: 普通用户不能查看系统操作日志

### 场景管理 (SCENE)

- [x] **SCENE-01**: 场景增加互斥组字段（mutex_group），如"居家模式"、"离家模式"、"睡眠模式"等为同一互斥组
- [x] **SCENE-02**: 启用场景时，如果同互斥组已有其他场景处于启用状态，自动禁用同组场景
- [x] **SCENE-03**: 触发场景时，根据场景配置同步更新关联设备的启用/禁用状态
- [x] **SCENE-04**: 场景列表接口返回时标注当前启用的互斥组信息

### 内容管理 (CONTENT)

- [x] **CONTENT-01**: 补充电影类型内容示例数据（增加5-10条）
- [x] **CONTENT-02**: 补充音乐类型内容示例数据（增加5-10条）
- [x] **CONTENT-03**: 补充游戏类型内容示例数据（增加5-10条）
- [x] **CONTENT-04**: 内容列表增加类型筛选功能

### 推荐管理 (RECOMMEND)

- [x] **RECOMMEND-01**: 推荐列表增加内容类型筛选
- [x] **RECOMMEND-02**: 推荐结果按内容类型分组展示
- [x] **RECOMMEND-03**: 用户偏好设置增加内容类型权重配置

### 权限管理 (PERMISSION)

- [x] **PERMISSION-01**: 定义管理员角色可执行的操作：用户管理、设备管理、场景管理、内容管理、推荐管理、日志查看
- [x] **PERMISSION-02**: 定义普通用户角色可执行的操作：个人设备管理、个人场景管理、内容浏览、推荐查看、个人偏好设置
- [x] **PERMISSION-03**: 接口层面实施权限校验，非授权操作返回403 Forbidden
