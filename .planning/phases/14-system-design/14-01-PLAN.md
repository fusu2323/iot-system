## 3. 时序图设计

### 3.1 用户登录时序图

```mermaid
sequenceDiagram
    participant Client as 客户端
    participant Controller as AuthController
    participant Service as AuthService
    participant Mapper as UserMapper
    participant DB as MySQL

    Client->>Controller: POST /api/auth/login
    Note over Controller: LoginRequest(username, password)

    Controller->>Service: login(loginRequest)

    Service->>Mapper: findByUsername(username)
    Mapper->>DB: SELECT * FROM user WHERE username=?

    alt 用户不存在
        DB-->>Mapper: null
        Mapper-->>Service: null
        Service-->>Controller: 抛出异常：用户不存在
        Controller-->>Client: 401: 用户不存在
    else 用户存在
        DB-->>Mapper: User对象
        Mapper-->>Service: User对象

        Service->>Service: 验证密码BCrypt

        alt 密码错误
            Service-->>Controller: 抛出异常：密码错误
            Controller-->>Client: 401: 密码错误
        else 密码正确
            Service->>Service: 生成JWT Token

            Service-->>Controller: LoginResponse(token, userInfo)
            Controller-->>Client: 200: {token, user}
        end
    end
```

### 3.2 设备控制时序图

```mermaid
sequenceDiagram
    participant Client as 客户端
    participant Controller as DeviceController
    participant Service as DeviceService
    participant Mapper as DeviceMapper
    participant LogService as LogService
    participant DB as MySQL

    Client->>Controller: PUT /api/devices/{id}/status
    Note over Controller: DeviceStatusUpdateDTO

    Controller->>Service: updateStatus(id, dto)

    Service->>Mapper: findById(id)
    Mapper->>DB: SELECT * FROM device WHERE id=?

    DB-->>Mapper: Device对象
    Mapper-->>Service: Device对象

    Service->>Service: 更新设备状态

    Service->>Mapper: update(device)
    Mapper->>DB: UPDATE device SET status=? WHERE id=?

    Service->>LogService: logOperation(userId, "UPDATE", "DEVICE", id)

    Service-->>Controller: 设备状态更新结果
    Controller-->>Client: 200: 更新成功
```

### 3.3 场景触发时序图

```mermaid
sequenceDiagram
    participant Client as 客户端
    participant Controller as SceneController
    participant Service as SceneService
    participant SceneMapper as SceneMapper
    participant DeviceMapper as DeviceMapper
    participant SceneDeviceMapper as SceneDeviceMapper
    participant DB as MySQL

    Client->>Controller: POST /api/scenes/{id}/trigger
    Controller->>Service: trigger(sceneId)

    Service->>SceneMapper: findById(sceneId)
    SceneMapper->>DB: SELECT * FROM scene WHERE id=?
    DB-->>SceneMapper: Scene对象
    SceneMapper-->>Service: Scene对象

    alt 场景不存在
        Service-->>Controller: 抛出异常：场景不存在
        Controller-->>Client: 404: 场景不存在
    else 场景存在
        Service->>SceneDeviceMapper: findBySceneId(sceneId)
        SceneDeviceMapper->>DB: SELECT * FROM scene_device WHERE scene_id=?
        DB-->>SceneDeviceMapper: SceneDevice列表
        SceneDeviceMapper-->>Service: SceneDevice列表

        loop 遍历每个场景设备
            Service->>DeviceMapper: findById(deviceId)
            DeviceMapper->>DB: SELECT * FROM device WHERE id=?

            Service->>Service: 更新设备状态

            Service->>DeviceMapper: update(device)
            DeviceMapper->>DB: UPDATE device SET status=? WHERE id=?
        end

        Service->>Service: 记录操作日志

        Service-->>Controller: 场景触发成功
        Controller-->>Client: 200: 场景已触发
    end
```

### 3.4 推荐生成时序图

```mermaid
sequenceDiagram
    participant Client as 客户端
    participant Controller as RecommendationController
    participant Service as RecommendationService
    participant ContentMapper as ContentMapper
    participant PreferenceMapper as PreferenceMapper
    participant RecommendationMapper as RecommendationMapper
    participant DB as MySQL

    Client->>Controller: GET /api/recommendations
    Note over Controller: 可选参数: type (MOVIE/MUSIC/GAME)

    Controller->>Service: getRecommendations(userId, type)

    Service->>PreferenceMapper: findByUserId(userId)
    PreferenceMapper->>DB: SELECT * FROM user_preference WHERE user_id=?

    DB-->>PreferenceMapper: UserPreference列表
    PreferenceMapper-->>Service: UserPreference列表

    Service->>Service: 计算推荐分数

    alt 有偏好设置
        Service->>ContentMapper: findByType(contentType)
        ContentMapper->>DB: SELECT * FROM content WHERE type=? AND deleted=0

        loop 遍历内容
            Service->>Service: 分数 = 基础分 + 偏好分 + 权重分
        end
    else 无偏好设置
        Service->>ContentMapper: findAll()
        ContentMapper->>DB: SELECT * FROM content WHERE deleted=0
    end

    DB-->>ContentMapper: Content列表
    ContentMapper-->>Service: Content列表

    Service->>Service: 按分数排序

    Service-->>Controller: GroupedRecommendationResponse
    Controller-->>Client: 200: 分组推荐结果
```

### 3.5 场景互斥时序图

```mermaid
sequenceDiagram
    participant Client as 客户端
    participant Controller as SceneController
    participant Service as SceneService
    participant SceneMapper as SceneMapper
    participant DB as MySQL

    Client->>Controller: POST /api/scenes/{id}/toggle
    Controller->>Service: toggle(sceneId)

    Service->>SceneMapper: findById(sceneId)
    SceneMapper->>DB: SELECT * FROM scene WHERE id=?
    DB-->>SceneMapper: Scene对象
    SceneMapper-->>Service: Scene对象

    Service->>Service: 检查mutex_group

    alt 有互斥组
        Service->>SceneMapper: findByMutexGroup(mutexGroup, userId)
        SceneMapper->>DB: SELECT * FROM scene WHERE mutex_group=? AND user_id=? AND deleted=0
        DB-->>SceneMapper: 同组场景列表
        SceneMapper-->>Service: 同组场景列表

        Service->>Service: 自动禁用同组其他场景

        loop 遍历同组场景
            Service->>SceneMapper: disable(scene.id)
            SceneMapper->>DB: UPDATE scene SET is_enabled=0 WHERE id=?
        end
    end

    Service->>Service: 启用当前场景

    Service->>SceneMapper: enable(sceneId)
    SceneMapper->>DB: UPDATE scene SET is_enabled=1 WHERE id=?

    Service-->>Controller: 切换成功
    Controller-->>Client: 200: 场景已切换
```
