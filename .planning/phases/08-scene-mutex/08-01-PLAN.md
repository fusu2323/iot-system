## Locked Decisions (per 08-CONTEXT.md)

- **D-01:** mutex_group = VARCHAR(50), human-readable string names (e.g. "居家模式")
- **D-02:** toggle() uses @Transactional — enable + auto-disable in same transaction
- **D-03:** SceneVO has activeGroupSceneId (Long) — null if no active scene in same mutex_group
- **D-04:** Existing scenes get NULL mutex_group (non-exclusive by default)

## toggle() Logic

When enabling (isEnabled becomes 1) AND mutexGroup is not NULL:
1. Query scenes: same userId + same mutexGroup + isEnabled=1 + id != currentId
2. Batch disable them (set isEnabled=0)

When disabling or mutexGroup is NULL: no mutex processing needed.

## list() / convertToVO() Logic

For each scene with non-NULL mutexGroup:
- Query same userId + same mutexGroup + isEnabled=1
- Set activeGroupSceneId to the first matching scene's ID (null if none enabled)

## Existing Patterns

- LambdaQueryWrapper for conditional queries
- @Transactional on service methods
- snake_case DB columns ↔ camelCase Java fields
- @Schema annotations on DTO/VO fields

    ```java
        @Override
        @Transactional
        public SceneVO toggle(Long id) {
            Scene scene = sceneMapper.selectById(id);
            if (scene == null || scene.getDeleted() == 1) {
                throw new BusinessException(ResultCode.SCENE_NOT_FOUND);
            }

            int currentEnabled = scene.getIsEnabled() != null ? scene.getIsEnabled() : 0;
            int newEnabled = (currentEnabled == 1) ? 0 : 1;
            scene.setIsEnabled(newEnabled);

            // If enabling and has a mutex group, auto-disable other scenes in same group
            if (newEnabled == 1 && scene.getMutexGroup() != null && scene.getUserId() != null) {
                LambdaQueryWrapper<Scene> wrapper = new LambdaQueryWrapper<>();
                wrapper.eq(Scene::getUserId, scene.getUserId())
                       .eq(Scene::getMutexGroup, scene.getMutexGroup())
                       .eq(Scene::getIsEnabled, 1)
                       .ne(Scene::getId, id)
                       .eq(Scene::getDeleted, 0);
                List<Scene> sameGroupEnabled = sceneMapper.selectList(wrapper);
                for (Scene s : sameGroupEnabled) {
                    s.setIsEnabled(0);
                    sceneMapper.updateById(s);
                    log.info("互斥禁用：sceneId={}, mutexGroup={}", s.getId(), scene.getMutexGroup());
                }
            }

            sceneMapper.updateById(scene);
            log.info("场景启用状态切换成功：{}, isEnabled={}", id, scene.getIsEnabled());
            operationLogService.log(scene.getUserId(), "TOGGLE", "SCENE", id, null);
            return convertToVO(scene);
        }
    ```
